# Security Policy for ProjectName

## Supported Versions

We actively maintain the latest stable release. Please report vulnerabilities in the supported versions.

## Reporting a Vulnerability

If you discover a security issue, please do **not open a public issue**. Instead, report it privately by emailing: <luisrguezgam@gmail.com>

Please include:

- Description of the issue
- Steps to reproduce
- Version of the project affected

We will respond within 72 hours and work to fix the issue as soon as possible.

## Security Updates
