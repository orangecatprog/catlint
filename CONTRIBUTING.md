# Contributing to CatLint

Thanks for taking the time to contribute this repository!

## Recommended workflow

1. Fork the repository
2. Create a branch for your contribution and use this syntax:
    - For features: `feature/<feature-name>`
    - For bug fixes: `bugfix/<bug-name>`
    - Fast fixes: `fastfix/<bug-name>`
3. Make smalls commits and with descriptive messages
4. Push your branch to your fork
5. Create a pull request to the branch that describes your contribution (bugfix/feature/fastfix)
6. Wait for the maintainers to review your pull request

## Code standards

Use this standard to format your code:

- Use TypeScript with ESLint rules
- Use the Prettier config in the root of the project
- Don't use 'eval' or 'new Function'
- Use the actual architecture of the project

## Reporting errors

If you find a bug, please report it by creating an issue in the repository.

1. Make sure you are using the latest version of the project
2. Check if the bug has already been reported
3. If the bug has not been reported, create a new issue explaining the bug:
4. Provide as much information as possible about the bug, including:
    - Steps to reproduce the bug
    - Expected behavior
    - Actual behavior
    - Screenshots
    - Version of the project and environment
